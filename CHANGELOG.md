### ⚠ BREAKING CHANGES

* restart versioning at 0.0.1 with release-please, trim the docs
* **image:** the runtime uid/gid changed from 100:101 to 1000:1000. Anything bind-mounting /downloads, /data or /home/spotiflac from a host path owned by 100:101 needs its ownership updated, or a rebuild with --build-arg PUID=100 --build-arg PGID=101.
* **image:** the image is ~5x larger and now ships a Python environment. Downstream images that added their own venv should drop it.
